# 📸 InstAm — Социальная сеть

Полноценное фулстек-приложение: соцсеть с постами, фото, комментариями, лайками, подписками, темами и админ-панелью.

## 🛠 Стек технологий

**Фронтенд:**
- React + Vite
- React Router (роутинг)
- Axios (запросы к API)
- CSS-переменные (4 темы)

**Бэкенд:**
- Node.js + Express
- SQLite (sql.js)
- JWT (авторизация)
- bcrypt (хеширование паролей)
- Multer (загрузка фото)

## ✨ Функционал

### Основное
- ✅ Регистрация и вход (по **email ИЛИ нику**)
- ✅ Создание постов (с **фото**)
- ✅ Комментарии к постам
- ✅ Лайки (❤️)
- ✅ Подписки на пользователей
- ✅ Поиск по постам и юзерам
- ✅ Профили с сеткой постов 3×3
- ✅ Загрузка аватарок
- ✅ **4 темы** (светлая, тёмная, фиолетовая, синяя)
- ✅ **Сохранение аккаунтов** (переключение между ними)
- ✅ **Страница правил**

### Роли
- 👤 **user** — обычный юзер
- 🛡️ **admin** — админ-панель с жалобами
- 👑 **dev** — разработчик (создаёт админов)

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Tyman4ikYa/instam-blog.git
cd instam-blog


blog-project/
├── server/                    # Бэкенд
│   ├── src/
│   │   ├── index.ts           # Точка входа
│   │   ├── db.ts              # БД + таблицы
│   │   ├── auth.ts            # JWT + bcrypt
│   │   ├── middleware/
│   │   │   └── authMiddleware.ts
│   │   └── routes/
│   │       ├── auth.ts        # Регистрация/вход
│   │       ├── posts.ts       # CRUD постов
│   │       ├── comments.ts    # Комментарии
│   │       ├── users.ts       # Профили, подписки
│   │       ├── admin.ts       # Админка, репорты
│   │       └── upload.ts      # Загрузка фото
│   ├── uploads/               # Загруженные файлы
│   └── database.sqlite        # БД
│
└── client/                    # Фронтенд
    ├── src/
    │   ├── pages/             # Страницы
    │   ├── components/        # Компоненты
    │   ├── context/           # AuthContext
    │   └── api/               # Axios
    └── public/






запуск бекенда

cd server
npm install
npm run dev

Сервер запустится на http://localhost:4000


запуск фронта

cd client
npm install
npm run dev

Фронтенд откроется на http://localhost:5173
